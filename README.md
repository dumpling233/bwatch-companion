# BWatch Companion

Public privacy policy and help pages for the BWatch Companion browser extension.

- [Privacy Policy / 隐私政策](https://dumpling233.github.io/bwatch-companion/extension-privacy.html)
- [Help / 使用帮助](https://dumpling233.github.io/bwatch-companion/)
- [Support / 问题反馈](https://github.com/dumpling233/bwatch-companion/issues)
- [BWatch monitor](https://bwatch.icu/monitor)

This repository contains public static documentation only. It does not contain extension implementation, credentials, or user data. Pages have no JavaScript, analytics, forms, or external images.

GitHub Pages publishes the root of the `main` branch. Update `extension-privacy.html` when data use or permissions change, and keep the privacy notice on the BWatch website consistent. Store approval and installation links are managed separately; this repository does not claim an extension has passed review.

Please do not post cookies, passwords, tokens, or raw authenticated network logs in public issues.
